# Nature Lens

한 장의 사진이 한 권의 기록이 되기까지. 뉴리프 자연 관찰 기록실.

**Live:** https://bang1lee.github.io/nature-lens/

## 지금 되는 것
사진 등록 → 수동 관찰 카드 → 동의 확인·사람 검수 → 기록집 → 인쇄/PDF 저장.
검색, 컬렉션, JSON 백업/복원, 오프라인 PWA를 포함합니다. 첫 화면의 예제 불러오기는 가상 식물 삽화 3건을 생성합니다. 실제 생물 관찰/종 판별 데이터가 아닙니다.

## 데이터와 현재 한계
- 기록은 해당 브라우저 IndexedDB에만 저장됩니다. 계정·클라우드 동기화·QR 공동 세션은 없습니다. 사이트 데이터 삭제 전에 반드시 JSON 백업을 내려받으세요.
- AI 자동 판별/편찬, Supabase, 국가생물종 DB는 **미연결**입니다. 식물 이름은 직접 확인합니다. 외부 AI 작성 여부를 표시할 수 있습니다.
- 정밀 GPS를 수집하지 않습니다. JPEG/PNG/WebP 이미지를 재인코딩해 EXIF를 제거합니다. 얼굴 자동 감지 기능은 없으며 인물이 포함되지 않은 사진만 운영자가 확인해서 사용해야 합니다.
- 검수·동의·인물 없음 확인이 완료된 카드만 출판합니다. 식용/약용 금지어 검사는 보조 장치이며 모든 표현을 판정하지 않습니다. 검수자는 이름·자유 텍스트의 위치/개인정보·효능 문구를 직접 확인해야 합니다.
- 작업실 저장 한도는 45MB / 500기록 / 100컬렉션입니다. 한도를 넘기는 저장·복원은 전체가 취소됩니다.
- 백업 복원은 50MB / 500기록 / 100컬렉션 이하입니다. 중복 ID는 유지하며 복원한 모든 관찰은 다시 검수해야 합니다. 사진은 복원할 때도 재인코딩합니다.
- 다른 기기로 공유하려면 JSON 백업 파일을 직접 전달합니다. 사이트 링크 자체는 개인 기록을 공유하지 않습니다.
- PDF는 브라우저 인쇄 창에서 저장합니다. A4, 배경 그래픽 켜기, 머리글/바닥글 끄기를 권장합니다.
- 앱 파일은 첫 온라인 방문 후 캐시됩니다. 브라우저/OS가 저장소를 회수할 수 있어 백업이 필요합니다.
- Google Fonts에서 글꼴을 받습니다. 관찰 사진·기록은 전송하지 않으며 오프라인에서는 시스템 글꼴로 대체됩니다.

## 개발
Node.js 22 이상.

```sh
npm ci
npm run dev
npm test
npm run typecheck
npx playwright install chromium
npm run test:e2e
npm run build
```

GitHub Pages 빌드:

```sh
NEXT_PUBLIC_BASE_PATH=/nature-lens npm run build
```

`out/`를 정적 호스팅합니다. GitHub Actions는 테스트·타입 검사·브라우저 검증이 실패하면 배포하지 않습니다. Pages의 Source를 GitHub Actions로 설정하세요. `main` push가 배포를 트리거합니다.

## 구조
- `src/lib/domain.ts`: 버전 1 데이터 계약과 출판 게이트
- `src/lib/storage.ts`: IndexedDB 레코드별 CRUD, 트랜잭션 복원
- `src/lib/image.ts`: 사진 형식·크기 제한, 메타데이터 제거
- `src/components/`: 관찰실, 편집 대화상자, 기록집
- `scripts/build-offline.mjs`: 빌드별 오프라인 캐시 생성
- `tests/`: 도메인 규칙 및 실제 브라우저 통합 검증

## 후속 연결
실제 운영자 로그인·공동 참여를 추가하기 전 Supabase 프로젝트/보안 정책 검수, 소유자 분리 RLS 실DB 테스트, Storage 접근 제어, 참가 토큰 만료/레이트리밋을 구현해야 합니다. Pl@ntNet·Claude 키는 서버/Edge Function에만 두고 정확도 테스트 및 비용 한도를 검증해야 합니다. 현재 로컬 전용 MVP에 서버 권한 검증이 된 것처럼 표시하지 않습니다.

PRD 진본과 전략 브리프는 뉴리프 위키에서 관리합니다. 이 저장소에는 서비스 소스와 운영 문서만 단방향 발행합니다.
