# 전문가 요청과 공개 종 목록 · 운영 준비안

이 마이그레이션은 기본적으로 요청 접수를 끕니다. 실제 운영 전 전문가의 신원·자격, 질문 검토, 응답과 정정·철회, 개인정보 처리 및 별도 사진 전달 절차를 마련해야 합니다. 새 사진과 기록 본문은 요청에 포함되지 않습니다. 사용자가 별도 동의하여 자신의 기존 공동 관찰 제출을 연결한 경우에만 운영자가 그 제출을 열어 사진과 내용을 확인합니다. 연결이 없는 요청은 일반 질문으로 처리합니다. 브라우저에 서비스 역할 키를 두지 않습니다.

신뢰된 운영자는 서버 측 service_role 또는 관리 콘솔에서 `expert_requests`의 `submission_id`가 있는 경우 해당 `community_submissions`를 확인하고, 해당 요청의 `id`와 실제 전문가 식별자 및 확인한 내용으로 `expert_responses(request_id, expert_id, response)`에 응답을 추가할 수 있습니다. 사용자는 기록의 요청 화면에서 새로고침하여 답변을 읽고 요청과 답변을 함께 삭제할 수 있습니다. 응답과 식별자에는 공개하면 안 되는 개인정보를 적지 않습니다. 요청 철회 시 연관 응답은 함께 삭제됩니다. 공동 관찰 제출을 철회하면 요청의 연결은 비워지며 해당 사진을 더 이상 조회할 수 없습니다.

공개 종 집계에는 별도의 실제 전문가 판정이 필요합니다. 신뢰된 운영자는 공개 동의된 `community_submissions`를 직접 검토한 후 해당 ID, 확인한 학명, 전문가 식별자, 판단 근거를 `expert_species_reviews`에 기록합니다. 운영 승인만으로는 집계되지 않습니다. 제출 철회나 판정 삭제 시 목록에서도 제거됩니다. 원래 관찰·사진·메모·위치는 종 페이지에 표시되지 않습니다.

운영 준비가 끝난 경우에만 신뢰된 운영자가 `expert_service_settings`의 단일 행 `accepting`을 `true`로 변경합니다. 접수 중단은 `false`입니다. 이 문서는 마이그레이션 적용이나 운영 개시를 의미하지 않습니다.
