# Nature Lens 안성 현장 운영 전략

작성 2026-10-08. 전략 제안이며 새 기능 구현·기관 협약·현장 조사 실행을 뜻하지 않는다.

## 방향과 가정

안성의 같은 장소를 반복 방문해 계절과 생태 변화를 기록하는 시민 관찰실로 운영한다. 첫 고객 가정은 지역 환경교육 운영자·교사·해설사, 첫 사용자는 이들이 인솔하는 주민·가족 소그룹이다. 실제 사용자 구성·운영 거점·예산·관찰 대상은 아직 미확정이다. 초기에는 운영자 1명, 해설·검수 담당 1명, 참여자 12~20명 규모를 제안한다. 참여자 수는 제안값이며 법정 인솔 기준이 아니다.

세 경로 비교: 개인 관광객은 유입이 쉬워도 재방문·표본 일관성이 약하다. 연구기관 직납은 검수·동의·표준 요구가 높다. 교육 운영자 중심 반복 관찰은 모집과 검수 책임이 명확해 첫 운영으로 추천한다. 이후 시민 모니터링과 연구 협력으로 확장한다.

## 지역 근거와 해석

모든 자료 확인일 2026-10-08. 센터 페이지 본문은 웹 도구 시간초과, ECOSEE 대용량 PDF는 전체 열기 실패로 검색 색인 내용만 사용했다. 과거 프로그램을 현재 모집으로 해석하지 않는다.

## 장소 전략

1. 준비 답사: 안성맞춤랜드의 관리된 보행 구간 또는 실제 운영 거점 인근 공원 1곳. 주차·화장실·그늘·비 피할 공간·휴대폰 통신·보행 접근성을 먼저 확인한다.
2. 반복 관찰: 답사를 통과한 안성시 내 안성천 구간 1곳, 고정 관찰 지점 3개, 같은 시간대·같은 관찰 시간으로 4회 재방문한다. 장소 사이 생물다양성 순위를 매기지 않는다.
3. 확장: 금광호수·고삼호수는 공개 보행 구간과 현재 통제·관리 주체를 확인한 뒤 별도 회차로 검토한다. 물가 진입·야간·희귀종 추적은 초기 프로그램에서 제외한다.

가을 시작이라면 낙엽·열매·식물의 상태와 동일 구도의 주변 풍경을 중심으로 한다. 특정 종의 출현을 사전 보장하지 않는다. 조류·수생생물은 검수자와 관찰 방법을 정한 후 확장한다.

## 90분 현장 운영안

- 출발 전: 온라인에서 앱을 열고 예제·사진 저장을 점검한다. 인터넷 없이 처음 접속 가능한 앱이라고 안내하지 않는다. iPhone Safari와 Android Chrome 실제 기기, 화면 잠금·재실행·비행기 모드·권한 거부·낮은 저장공간을 사전 시험한다.
- 0~10분: 안전·촬영·연구 활용 선택 동의 안내, 집결 위치와 종료 시간 공유.
- 10~20분: 인솔자와 사진 1건 저장 연습. 종 이름은 모름 허용.
- 20~60분: 3개 지점에서 사진·짧은 메모 기록. 지점별 관찰 시간과 미발견도 운영자 조사표에 남긴다.
- 60~75분: 그늘/실내에서 검수. AI 제안과 사람의 확인을 구분한다. 현재 실제 AI 식별은 미연결이므로 사람 검수로 운영한다.
- 75~90분: 백업 파일 생성·열기 확인, 동의한 기록만 수합, 개인 관찰 카드나 회차 저널 제공.
- 종료 후 48시간 이내: 담당자가 누락·중복·사진 품질 검토하고 요약을 참여자에게 돌려준다. 발송은 별도 실행 승인이 필요하다.

현재 앱은 브라우저 저장소 중심이며 자동 클라우드 백업이 아니다. 임시 전달은 영구 연구 보관소가 아니다. 24시간 안에 수신·백업을 확인한다. 현장 최초 운영에서는 대량 전달 대신 기기별 파일 백업을 기본으로 하고, 동의받은 자료의 수합 경로·보관 책임자를 사전에 정한다.

## 제품 개선 우선순위 — 제안, 미구현

P0 현장 신뢰성: 큰 촬영/저장 버튼, 저장 완료와 사진 수, 오프라인 상태, 마지막 백업 시각, 앱 재실행 복구. 햇빛·한 손·장갑 사용은 실제 기기에서 측정한다.
P0 단체 운영: 회차 코드·조사 지점·관찰 시간, 운영자의 수신 확인, 연구 제공 동의와 일반 이용 동의 분리.
P0 전달 용량·한도: 현재 암호문1MiB, 활성32건, 최근24시간64건, IP당6건. 같은 와이파이·통신사 공유 주소를 쓰는 참여자에게 불리할 수 있다. 무조건 제한을 없애지 않고 운영자 인증과 행사별 생성 허용량·총비용 상한을 함께 설계한다. 파일 백업 대안은 계속 제공한다.
P1 검수와 연구: 미확인/후보/사람 확인 구분, 수정 이력, 표준 CSV 내보내기, 정확한 위치 별도 관리, 민감종 공개 위치 제한. 개인 원본과 연구 제출본 분리.
P2 지역 경험: 운영자가 확인한 계절별 관찰 과제, 이전 방문 사진 비교, 내 안성 관찰 저널. 지도·관광 보상·공개 순위는 검증 이후 판단한다.

## 연구·공익 전략

첫 질문은 ‘같은 지점에서 같은 시간 관찰했을 때 계절에 따라 기록되는 식물 상태가 어떻게 달라지는가’로 좁힌다. 사진 업로드 수는 실제 개체수나 생물다양성 증가량이 아니다. 관찰 시간·지점·관찰자 수·날씨·조사 방법을 함께 수집하고 미발견과 미조사를 구분한다. 개발·오염의 인과효과는 시민 사진만으로 단정하지 않는다.

공개층: 대략적 구역·검수된 관찰 카드. 운영층: 회차·연락 및 동의·검수 상태를 최소 범위로 관리. 연구층: 별도 동의·이용 목적·보관기간·접근 책임을 정한 제출 자료. 어린이 얼굴·사유지·민감종 정확한 위치는 공개 자료에서 제외한다. 법적 적합성 확정 판단은 별도 검토 대상이다.

안성환경교육센터에는 ‘4회 수업과 결과 저널’, 한경국립대에는 ‘작은 조사 질문과 검수 양식’, 안성천 활동단체에는 ‘기존 조사표의 입력 부담 감소’를 제안한다. 어느 기관에도 연락하거나 데이터를 보내지 않았다. 시에는 검증된 회차 결과·결측률·재참여율·데이터 예시를 갖춘 뒤 시범 운영을 제안한다. 봉사시간·지원금·지역화폐·세액공제는 협약이나 공식 요건 확인 없이 약속하지 않는다.

## 8주 실행과 판단

1~2주: 운영자 인터뷰3명(제안), 장소1곳 답사, 실제 휴대폰5~8대 점검, 첫 회차 양식 확정.
3~4주: 12~20명 소그룹 2회. 대형 버튼과 짧은 양식이 첫 기록 완료 시간을 줄인다는 가설을 시험한다. 같은 참가자가 순서를 교차해 기존 흐름/개선 시안을 사용; 참가자·기기 차이는 함께 기록한다. 신뢰성 수정 전에는 새 참가자 확대 금지.
5~6주: 같은 장소 반복 관찰 누적4회, 사람이 검수한 기록과 반려 이유 정리.
7~8주: 운영 결과1쪽, 개인 관찰 저널, 동의된 샘플 자료, 실제 운영비 정리. 운영자1곳과 다음 회차 재사용 의향을 확인한다.

목표값(실측 아님): 안내 뒤 첫 기록 중앙값60초 이내, 세션 저장 성공95% 이상, 원본 유실0건, 동의/수신 확인 누락0건, 4회 중2회 이상 재참여60% 이상, 필수 항목 완성90% 이상. 적은 표본은 분모와 건수를 함께 표시한다. 하나라도 데이터 유실 또는 동의 오류가 나면 확대를 중단하고 복구·원인을 확인한다. 현장 통제·악천후·안전 문제 발생 시 실내 검수 활동으로 전환한다.

예산은 강사·검수 인건비, 답사/교통, 현장 준비, 자료 정리, 인쇄, 서버 순서로 항목화한다. 금액과 유료 요금제는 확정하지 않는다. 첫 수익 가설은 교육 운영기관의 회차 운영·결과보고·저널 제작 비용이며, 이용자 관찰 데이터 판매를 전제로 하지 않는다.
