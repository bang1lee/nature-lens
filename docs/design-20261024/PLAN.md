# 승인된 통합 디자인 · 2026-10-24

숲 사진이 주인공이고, 조작부에는 물의 투명함, 읽는 영역에는 종이의 온기를 둔다. Seek의 쉬운 촬영, Apple의 조작 영역 분리, Emergence의 생태 편집을 참고하되 브랜드 자산은 복제하지 않는다.

- 색: 종이 #f5f2e9, 잉크 #203c30, 이끼 #536a43, 물빛 #dde9df, 햇빛 #e9dcae.
- 글꼴: 기존 한국어 serif 변수로 제목, 기존 sans로 안내·버튼. 새 폰트 다운로드 없음.
- 화면: 로고 → 큰 이끼 사진/짧은 제목/촬영 → 마지막 관찰로 돌아가기 → 기록 흐름 → 공동 도감 시연. 왼쪽 정렬, 숫자는 순서에만 사용.
- 조작: 이동 180–240ms, 버튼 눌림 120ms. 무한 배경 애니메이션·3D·영상 없음. 유리는 내비게이션만; reduced motion/contrast 지원.
- 성능: 필요할 때만 설정·식별·도감 코드 로드. 동일 로컬 정적 빌드/390px/서비스워커 차단/3회 초기 JS와 LCP·CLS 비교. 오프라인 사전 캐시는 별도 비용이며 총 다운로드 감소와 혼동하지 않는다.
- 품질: 기존 77개 단위, 저장/재관찰/월간 도감 회귀, 모바일·desktop·축소 동작·접근성. 실기기 INP·배터리는 별도 미검증.
