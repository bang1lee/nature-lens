# 한국 종 평가 1차 결과와 다음 작업 (2026-10-16)

확인 시각: 2026-10-16 KST. 상태: **탐색 평가 결과. 앱 코드 변경 없음, 표시 정책 결정 전.**

작성: 수집·실행은 **Codex**(사용자 로컬), 검수·분석과 이 요약은 **Claude** (Claude Code, Anthropic) 세션 https://claude.ai/code/session_016tEFHCFnPnN22Uk8qh7xwt . 원본 근거(사진별 결과, 독립 QA, 앱 감사)는 비공개 저장소 `bang1lee/claude-workspace`의 `reverse-engineering/naturelens-seek/evidence/korea-eval-20261016/`에 있다.

## 1. 무엇을 쟀나
- iNaturalist 한국 연구등급 관측에서 99종 197장을 모았다. 모델이 아는 종 60종 120장, 모델 밖 종 39종 77장이다.
- 라이선스는 CC-BY-NC 195장, CC0 2장이다. **평가에만 썼고** 학습, 앱 콘텐츠, 재배포에는 쓰지 않는다.
- 공개 샘플 모델(507종)에 Seek 판별 방식을 적용하고, 위치 사용 방식 4가지와 고도 보정 2가지를 비교했다. 임계값은 70이다.

## 2. 결과
| 설정 | 아는 종 · 종까지 맞힘 | 모델 밖 종 · 틀린 이름 (95% 구간) |
|---|---:|---:|
| 위치 없음 | 22.5% | 23.4% (15~34%) |
| Seek 방식(위치 가중치 1) | 45.8% | 28.6% (20~40%) |
| 완화(위치 가중치 0.5) | 40.0% | 20.8% (13~31%) |
| 두 설정이 합의한 상위 분류까지만 표시 | 22.5% | ≤10.4% |

- **모든 설정에서 모델 밖 종에 틀린 이름을 붙이는 비율이 목표 5%를 넘는다.** 그래서 종 이름을 자동으로 확정해 보여 주는 기능은 넣지 않는다.
- 한국 종에서는 위치 정보가 정답률을 크게 올린다(22.5% → 45.8%). 대신 모델이 모르는 종을 더 자주 틀린다.
- 해안·섬 고도 보정의 효과는 이 표본에서 거의 없었다.
- 식물 중 모델 밖 표본은 1종 2장뿐이라서 식물에 대해서는 판단하지 않는다.
- 표본이 작아 0/77이어도 오답률 상한이 4.8%다. 목표를 확인하려면 모델 밖 사진을 훨씬 늘려야 한다.

## 3. 이 앱에 대한 의미
모델 성능이 부족해도 관찰 참여를 막을 필요는 없다. 핵심은 **AI가 낸 이름을 검수된 이름처럼 저장하거나 공개하지 않는 것**이다.

권장 흐름(Codex 제안, Claude 동의):
1. 사진을 남긴다.
2. 결과를 후보 / 상위 분류 / 판단 유보 중 하나로 설명한다.
3. 이름이 없어도 비공개 관찰로 저장한다.
4. 같은 대상을 다시 찍는다.
5. 전문가가 근거와 함께 확인한다.
6. 공개 범위와 발행에 동의를 받는다.
7. QR 이름표와 월간 도감으로 이어진다.

"합의한 상위 분류까지만 표시" 정책은 2단계의 "상위 분류" 답과 자연스럽게 맞물린다.
