## 발견하고 수정한 문제

새 기록 저장 직후 화면의 수정 시각과 DB의 수정 시각이 달라 후보 적용이 충돌했습니다. saveObservation이 실제 저장된 레코드를 반환하고 QuickCapture가 그 값을 사용하도록 수정했습니다. 기존 다중 창 충돌 방지는 유지했습니다. 실패했던 모바일/데스크톱 후보 저장 시나리오가 수정 후 통과했습니다.

Mac 촬영 화면이 기본 창보다 길어지는 것을 실제 창에서 확인해 데스크톱 최소 높이를 조정했습니다. 사진 재인코딩은 데이터 URL을 메모리에서 직접 해석해, 네이티브 CSP에서 data URL fetch를 허용할 필요가 없게 했습니다.

동시 Next 빌드 중 생성 타입 파일이 바뀌어 타입 검사 1회가 실패했습니다. 전용 빌드 디렉터리를 분리하고 최종 빌드→타입 검사를 순서대로 실행해 통과했습니다. 임시 실패를 최종 통과로 덮어 숨기지 않습니다.
