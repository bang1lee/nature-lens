# 단순한 관찰 UI + 회원 참여

2026-10-29. 승인 범위: 기존 디자인 유지, 촬영→식별/예측→저장 단순화, 로그인·점수 회귀 검증, 배포.

## 구현 계약
- 사진 확인 화면: 두 라디오 선택, 계속하기가 기기 저장을 먼저 완료한 뒤 같은 화면에서 로그인/식별로 연결. 저장 실패 시 다음 단계/외부 전송 금지.
- 날짜·메모·위치는 기록 더하기. GPS 오류는 위치 영역. 이름 없이 저장은 비회원 가능.
- 외부 전송 동의 2개 기본 미선택, 로그인 전에는 숨김. 일반 화면의 시연 선택 제거. 결과·출처/예측 규칙은 펼침.
- 홈 예시 이야기는 펼침. 회원 활동 카드에 공개 별칭 + 총점 + 등급. 계정·공동 관찰 기존 계약 유지.
- 일일 관찰: 자가 신고 참여 +2점, 한국 시간 하루 1회, 동일 기록 재사용 금지. 직접 버튼을 눌러 기록 UUID/관찰일만 Supabase로 보냄. 사진·좌표 미전송. 서버가 사용자·날짜·점수 결정.
- 총점=기존 예측 점수+일일 참여. 씨앗 0 / 새싹 20 / 나무 100. 전문가 인증·관찰 진위 인증 아님.
- 실행 중 사용자 점수 생성/사진 전송은 하지 않음. 실회원 적립은 사용자가 참여할 때 확인 필요.
