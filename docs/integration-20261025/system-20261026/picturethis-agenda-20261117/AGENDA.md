# PictureThis 대비 구현 아젠다 · 2026-11-17

기준 커밋 `5128e78`. PictureThis의 공개 자료(App Store 설명, 공식 FAQ, 리뷰)에서 확인되는 기능과 Nature Lens 현재 코드·운영 응답을 비교했다. 앱 바이너리·비공개 API는 분석하지 않았다. 화면·문구·이미지를 복제하지 않고, 같은 사용자 가치를 Nature Lens의 디자인으로 구현한다.

## 1. 비교 요약

| PictureThis가 주는 것 | Nature Lens 현재 | 차이 |
|---|---|---|
| 가입 없이 사진 한 장으로 즉시 식별 | 가입 없는 식별 연결됨 (11-16) | 첫 연결이 30초 이상 걸릴 수 있음 (무료 서버가 잠듦) |
| 결과에 이름·참고 사진·설명 | 영어 이름·낮은 점수만 표시 | **이번에 한국어 이름·설명·참고 사진 추가** |
| 식물 백과(특징·관리법·독성) | 없음 | 위키백과 요약만 연결. 관리법·독성 데이터는 출처 필요 |
| My Garden(내 식물 모음) | 내 기록·컬렉션·월간 도감 | 종별 묶음 보기 없음 |
| 물주기 등 알림 | 없음 | 푸시 서버·구독 저장 필요 |
| 병해 진단 | 없음 | 유료 공급자 키 필요 |
| 이름 검색 | 내 기록 검색만 | 종 검색·백과 진입 없음 |
| 여러 장으로 식별 | 한 장 | 공급자는 여러 장 지원, 서버·화면 미구현 |
| 조도계·전문가 상담 | 없음 | 우선순위 낮음 |

Nature Lens만의 것: 같은 대상 재관찰, 월간 도감, 다음날 확인(예상·점수), 공개 구역 지도. 이 흐름은 유지한다.

## 2. 프론트엔드

| # | 항목 | 상태 | 내용 |
|---|---|---|---|
| F1 | 식별 결과 카드 | **완료 (이번)** | 한국어 이름을 크게, 학명, 닮은 정도 문구, 참고 사진, 두 문장 설명, 출처 표시. 다른 후보에도 한국어 이름. |
| F2 | 기록 상세의 식물 정보 | **완료 (이번)** | 학명이 있는 기록에 식물 정보 카드 표시. |
| F3 | 첫 연결 지연 안내 | **완료 (이번)** | 앱을 열 때 식별 서버를 미리 깨우고, 8초 넘으면 "처음 연결은 30초쯤 걸릴 수 있어요" 안내. |
| F4 | 홈을 촬영 중심으로 | 다음 | 첫 화면에서 촬영·사진 선택을 가장 크게. 안내 문단 축소. |
| F5 | 종별 모아보기 | 다음 | 같은 학명의 기록을 한 식물로 묶어 보여주기. 데이터는 이미 있음. |
| F6 | 이름 검색·백과 진입 | 다음 | 이름을 입력하면 식물 카드로 이동. F1 조회 모듈 재사용. |
| F7 | 여러 장 식별 | 서버 B3 뒤 | 잎·꽃·전체 사진을 함께 보내기. |
| F8 | 알림 설정 화면 | 서버 B6 뒤 | 재관찰·물주기 알림 켜기. |
| F9 | 설정 화면 정리 | 다음 | 긴 정책 문단을 접고 개발 용어 제거. |

## 3. 백엔드

| # | 항목 | 상태 | 내용 |
|---|---|---|---|
| B1 | 식별 서버 상시 응답 | **결정 필요** | 무료 Render는 15분 뒤 잠들어 첫 응답이 30초 이상. 선택지: Cloudflare Worker로 이전(무료·잠들지 않음, 키 재설정 필요) 또는 Render 유료 전환. F3은 임시 완화책. |
| B2 | 한국어 이름·설명 | **완료 (이번, 클라이언트)** | 위키데이터 정확 일치 → 한국어 위키백과 요약. 표준 식물명이 아니므로 출처 표시. 국가표준식물목록 연결은 별도 데이터 필요. |
| B3 | 공급자 응답 확장 | 다음 | Pl@ntNet의 과·속, 참고 이미지, 여러 장 입력을 게이트웨이 계약에 추가. 클라이언트 먼저 배포 후 서버 배포(구버전 클라이언트는 추가 필드를 거부함). |
| B4 | 이용 한도 재조정 | **결정 필요** | 현재 손님 1인 하루 5회, 전체 하루 50회. Pl@ntNet 무료 한도는 하루 500회. 실제 사용에는 전체 50회가 부족. |
| B5 | 남용·저장량 통제 | 다음 | 손님 계정 재생성으로 개인 한도 우회 가능. 전체 사진 저장 상한 없음. 과거 공개 쓰기 경로 점검. |
| B6 | 알림 | 나중 | 웹 푸시 구독 저장, 예약 발송(Worker cron). iOS는 홈 화면 설치 후에만 가능. |
| B7 | 병해 진단 | 나중 | 유료 공급자 계약 필요. 지금은 구현하지 않음. |
| B8 | 기기 간 이어쓰기 | 다음 | 손님 기록을 회원 계정에 연결, 다른 기기에서 복구. |
| B9 | 공개 철회 | 다음 | 공개 사진을 화면에서 내릴 수 있게. 현재 UI 없음. |

## 4. 검증 구분

- 실제 확인: 위키데이터·위키백과 조회 8종(민들레속, 소나무, 개나리, 개망초, 느티나무, 진달래, 신갈나무, 토끼풀) 모두 0.5~1.1초에 한국어 이름·설명·사진 반환.
- 모의 확인: 결과 카드 표시, 한국어 이름으로 기록 저장, 접근성 검사.
- 미확인: 운영 배포 후 실제 사진 식별과 카드 표시의 종단 흐름. 한국어 문서가 없는 종의 실제 빈도.

## 5. 한계

- 한국어 이름은 위키백과 문서명이다. 국가표준식물목록과 다를 수 있다.
- 참고 사진은 사용자가 찍은 개체가 아니다. 카드에 이를 표시한다.
- 종 문서가 없으면 속(屬) 정보로 대신하고 그 사실을 표시한다.
- 조회 시 학명만 외부로 보낸다. 사진·계정·위치는 보내지 않는다.
