# 합성 실시간 이벤트 검증 · 2026-11-14

실제 사용자나 실제 관찰 사진은 쓰지 않았다. 이메일·비밀번호 없는 합성 계정, 1픽셀 합성 PNG와 실제 생태 관찰이 아님을 밝힌 기록을 사용했다. 두 독립 익명 클라이언트가 안전한 `community_map_points` 테이블에 구독한 뒤, 주 담당자가 고정 시험 ID에 한해 생성과 철회 SQL을 실행했다.

| 조작 | 독립 구독 1 | 독립 구독 2 | 각 클라이언트 재조회 |
|---|---|---|---|
| 합성 공개 기록 생성 | INSERT · 11:08:37.984 UTC | INSERT · 11:08:37.977 UTC | 존재 |
| 지도 동의 철회 및 반려 | DELETE · 11:09:18.967 UTC | DELETE · 11:09:18.965 UTC | 없음 |

후속 익명 REST 검사에서 지정 시험 ID의 지도 점과 공개 피드는 각각 HTTP 200, 0건이었다. 클라이언트 두 채널은 정상 종료했다. 이는 지정된 합성 레코드에 대한 이번 실시간 왕복 결과이며 모든 네트워크 조건에서의 전달을 보장하지 않는다.

`realtime-probe-01-create.sql` / `02-withdraw.sql` / `03-cleanup.sql`은 별도 트랜잭션이다. 계정 생성 시 자동 프로필 트리거가 있는 상황을 포함해 격리 PGlite에서 생성·철회·정리 흐름을 검증했지만 실제 인증 스키마의 모든 트리거는 이에 포함되지 않는다. 현재 원격에서 공개 노출은 철회됐으며, 합성 원본 제출·계정의 영구 삭제는 아직 실행하지 않았다.

## 후속 정리 완료
사용자 실행 직전 승인 후 03-cleanup.sql 실행 성공. 별도 DB 조회로 합성 계정·프로필·제출·지도 점 모두 0건 확인. 기존 회원 데이터 변경 없음. probe-cleanup.png 참조. 이전 미정리 상태 기록은 이 결과로 갱신된다.
