# 실제 로그인 차단 및 독립 검증 · 2026-10-28

## 확인된 현재 상태
- Aside의 실제 앱 설정에서 로그인 메일 발송 한도 오류를 확인했다. 추가 이메일 요청·인증 우회·브라우저 간 토큰 이동을 하지 않았다. 실제 로그인 성공은 미확인이다.
- 앞서 Aside에 표시된 로그인 링크 완료 실패와 메일 발송 제한은 별개의 단계다. 현재는 새 메일 왕복을 검사할 수 없다.
- 일반 사용자 가입에는 기본 SMTP의 수신자 제한과 낮은 한도 때문에 별도 발송 설정이 필요하다. 사용자에게 발신 도메인 보유 여부만 질문했으며 답변 대기 중이다. API 키는 채팅으로 받지 않는다.
- 공식 자료: https://supabase.com/docs/guides/auth/auth-smtp , https://resend.com/docs/send-with-supabase-smtp . 기본 한도는 현재 시간당 2건이며 서비스 정책 변경 가능. 정확한 해제 시각은 확인되지 않았다.

## 배포 앱의 로컬 기록 검증
- production-observation.json / production-observation-retry2.log: 별도 Playwright 브라우저에서 앨범 테스트 이미지 → 저장 → 동일 개체 재관찰 → 새로고침 후 기록 유지 → 월간 도감 2기록/1대상/1재관찰 확인. 외부 쓰기 요청 0건. 사용자 브라우저·사진·기록에 접근하지 않았다.
- 최초 검사는 저장 완료와 수화 완료를 기다리지 않아 실패했다. 첫 재시도는 page.goto의 load 30초 초과였다. 최종 검사는 저장 완료 화면, 최초 렌더 이후 날짜, 새로고침 후 실제 기록 카드를 기다려 통과했다. 앱 코드를 바꿔 통과시킨 검사가 아니다.
- 실제 카메라 하드웨어, 로그인, 서버 저장, 식별 공급자 응답을 검증한 결과는 아니다.
