# 바로 알기 / 내일의 발견 · 구현 계약

사용자 확정: 식별·예측·점수는 로그인 필수. 촬영·기기저장은 비회원도 가능. 기존 디자인과 모델 유지.

- 지금 알기: 기존 로그인·사진 동의 후 바로 후보. 전문가 확정 이름으로 표시하지 않음.
- 내일의 발견: 사진을 기기에 저장 → 로그인 → 예상 이름/이유 입력 → 개인정보 없음 및 외부 전송·서버 저장 동의 → 사진을 지금 분석 → 후보는 서버에서 숨김 → 한국시간 다음날09시 이후 앱에서 공개 → 예상과 비교.
- 앱 홈에 참여한 기록 진입점을 제공. 외부 푸시/이메일 예약은 미구현. ‘다음 날’은 한국시간이며 기기 시계 변경으로 서버 공개 시간을 앞당길 수 없음.
- AI 첫 후보 ≥0.7, 2순위와 ≥0.15 차이, 공백/대소문자 정규화 후 한국어 이름 또는 학명 완전 일치:10점. 불확실/불일치:0점. 점수는 전문가 동정이나 생물 안전성을 보증하지 않음. 사소한 오타·다른 통용명은 인정하지 않는 MVP 한계.
- 서버 검증 로그인 ID에 묶인 예측. 예상은 수정 불가. 결과·점수는 직접 DB 접근 불가. 동일 계정의 동일 정제 사진 해시 중복 금지. 즉시 결과를 보거나 미리 공개하면 해당 사진의 점수 자격 소멸. 변형 사진·다계정까지 막는 신원 증명이 아니므로 현금/상품/공개 순위 없음.
- 기기에는 참여 ID/선택 방식만 추가 저장. 사진 교체 시 연결 해제. 재관찰은 새 사진·새 예측. 서버에는 사진이 아닌 해시·예상·후보·점수 보관. 정책 화면 명시.

## 실행 그래프
사진 저장 → 인증 → 명시적 동의 → 서버 할당량 → 사진 정제 → 서버 예측 잠금 → 공급자 → 비공개 결과 → 서버 시각 확인 → 원자적 공개/한 번 적립 → 후보 선택 시 기기 관찰 반영.
실패: 결과 실패면 같은 예측으로 재시도(다시 동의/한도 소모), 응답 유실이면 기존 사진 해시로 회수. 5분 이상 미완료 분석은 재시도 허용. 결과 열기/새로고침은 사진 재전송 없음.

## 검증과 활성화
단위/API 경계 → PGlite 실제 SQL → 모의 브라우저 → 타입/빌드 → 기존 회귀 → 원격 migration → 서버 DISCOVERY_ENABLED → 프론트 배포 → 읽기 전용 상태 확인. 실제 사진·실제 점수 적립 검증은 사용자 동의한 참여에서 별도 수행. 모의 결과를 실제 적립이라 보고하지 않는다.
