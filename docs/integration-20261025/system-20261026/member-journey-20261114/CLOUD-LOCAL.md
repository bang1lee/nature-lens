# 공동 관찰 제출 · 로컬 검수 2026-11-14

## 확인과 수정

- 공개 구역 조회가 실패하면 빈 목록과 구분하여 표시하고, 재확인을 제공한다. 재조회 실패 시 이전 구역 선택과 지도 동의를 지우며, 재조회 중에는 제출을 막는다. 성공 후에도 지도 동의를 다시 확인한다.
- 제출 성공 뒤 내 제출 목록 조회만 실패하면 검수 대기 제출 완료 상태를 보존하고 목록 재확인을 안내한다. 성공 시 선택한 기록·구역·제출 및 지도 동의를 초기화한다. 제출 요청이 15초 넘게 응답하지 않으면 중복 제출을 피하도록 목록을 먼저 확인하라고 안내한다. 응답 대기는 서버 처리를 취소했다는 뜻이 아니다.
- 선택한 기록에 제출 전 필요한 이름·메모·기록의 출판 동의/인물 확인이 빠져 있으면 사유를 표시한다. 모바일에서는 명시적으로 선택한 기록을 수정하는 콜백을 제공하며, 동의를 자동 설정하지 않는다. 구역 공개는 별도 동의와 운영 검수가 필요하며 unknown/protected 값을 common으로 바꾸지 않는다.
- 지도 선택 및 제출 정보의 검수 대기와 승인 후 공개를 구분한다. 정밀 GPS는 제출 페이로드에 포함되지 않는다.
