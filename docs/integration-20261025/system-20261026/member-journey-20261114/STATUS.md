## 완료 기준
사진 선택/촬영 실패 복귀 → 로그인 후 별도 전송 동의 → 실제 식별의 후보/실패 구분 → 기기 저장 → 모바일에서 제출에 필요한 항목 확인 → 지도 구역과 공개 동의 → pending 제출(즉시 공개 아님) → 같은 개체 재관찰 → 새로고침 후 연결 유지. 로그인과 점수 계약/기존 디자인/식별 모델 유지.

## 역할과 작업 경로

## 현재
- 운영 앱 설정에서 로그아웃 확인. 사용자에게 같은 브라우저 로그인 한 단계 요청 중. 기존 사용자 사진은 자동 전송하지 않음.
- 이전 지도 DB/실시간 승인·철회 검증은 release-20261114 참조. 이는 일반회원 UI 제출 검사 대체가 아님.
- 기존 운영 비회원 흐름 스크립트 기본 Playwright 실행 파일 없음. AUDIT_BROWSER_CHANNEL 선택으로 설치된 Chrome 이용하도록 하네스 개선, 실행 중.
- 회원 모의검사와 실제 로그인/식별/제출을 분리하며 새 테스트 실패를 성공으로 처리하지 않는다.

## 아직 완료가 아닌 범위
실제 회원 로그인 후 PlantNet 공급자 식별, 인증된 사용자 UI로 실제 pending 제출, 실제 기기 카메라/GPS. 이전 실제 지도 합성 INSERT/DELETE 검사는 관리자 SQL의 안전한 투영 검사였으며 회원 UI의 RLS/사진 제출 검사가 아니다. 로그인/점수 모의 회귀는 verify:local에 포함되지만 실제 점수 적립을 주장하지 않는다.

## 재개
사용자는 앱 설정→함께 관찰하기에서 로그인, 이메일 링크도 같은 브라우저로 열고 알려준다. 이후 사용자 본인이 선택·동의한 식물 사진으로 실제 식별 결과/저장/재관찰 확인, 별도 제출·지도 공개 동의 후 pending 확인. 운영 기록을 임의 승인하거나 삭제하지 않는다.

## Aside 실제 회원 연결 확인
사용자 로그인 브라우저는 Aside. 그 브라우저의 설정 화면에서 로그인되어 있어요, 기존 별칭, 관찰 점수 조회, 내 제출 목록 조회 및 청량산 구역 선택지를 확인했다. Codex IAB 세션은 별도여서 로그인 전이다. 실제 회원 세션 확인은 완료했으나 사진 선택·공급자 호출·pending 제출은 아직 대기. 사용자에게 Aside 사진 선택 한 단계 안내했다. 동시에 기존 세션이 정상인데 로그인 링크 완료 실패 안내가 남는 혼동을 발견해 콜백 상태 표시를 점검 중.
