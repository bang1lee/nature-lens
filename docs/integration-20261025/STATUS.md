## 검증 범위

이 폴더의 unit.log, types.log, e2e.log, app.log는 실제 Git 저장소에서 실행한 증거다. 서비스 mock 성공은 운영 로그인·식별 성공이 아니다. expect-cli는 Claude 인증 누락으로 실행 실패; Playwright/axe 검증으로 보완한다. OpenRig CLI는 이 환경에서 찾을 수 없어 원격 작업 잠금을 주장하지 않는다.

## 사용자에게 표시할 상태

기기에 저장한 사진/관찰은 비공개 로컬 자료다. 로그인·클라우드 동기화·실제 외부 식별·전문가 인증·공개 발행은 별개다. 현재 공개 Pages의 전송 서버는 미연결이므로 파일 백업을 사용한다. 평가 사진과 연구 코어는 이번 통합에서 변경/전송하지 않았다.
